## Быстрый запуск (Windows)

Открыть `run.cmd`

Скрипт сам создаст виртуальное окружение `.venv`, установит Django,
применит миграции, заполнит базу демонстрационными данными и запустит сервер
на `http://127.0.0.1:8000/`, открыв браузер.

## Ручной запуск

```powershell
cd app
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8000
```

Остановить сервер — `Ctrl+C` в консоли.

## Что можно проверить

Сценарий клиента. Регистрация или вход по телефону → каталог с поиском и
фильтром по категориям → «Выбрать время» → дата и слот конкретного мастера →
контакты и согласие → оплата. После оплаты открывается страница заказа с
временной шкалой статусов, платежом и уведомлениями; после закрытия заказа
появляется форма отзыва. В личном кабинете — история заказов, повтор записи,
редактирование контактов и список уведомлений.

Тестовые карты. `4111 1111 1111 1111` — успешная оплата,
`4111 1111 1111 0000` — имитация отказа банка. Варианты «СБП» и
«оплата после визита» тоже работают: во втором случае платёж закрывается
при закрытии заказа оператором.

Сценарий оператора. Вход → «Календарь» (неделя, занятость четырёх
исполнителей) → клик по заказу открывает карточку: подтвердить, закрыть,
отменить, перенести на другой слот. «Заказы» — реестр с фильтрами по статусу,
номеру, фамилии и телефону. «Новая заявка» — оформление по звонку.
«Отчёты» — загрузка, средний чек, выручка, отмены, разрез по исполнителям
за выбранный период. «Слоты» — добавление рабочих интервалов на несколько дней
вперёд и удаление свободных слотов. «Тарифы» — добавление тарифного плана
с коэффициентами.

Программный интерфейс (REST, Django REST framework).


## Проверка работоспособности

```powershell
python smoke_test.py
python api_test.py
```

Первый скрипт проходит сквозной сценарий через тестовый клиент Django: создание
заказа, отказ и успех оплаты, смену статусов, страницы оператора. Второй проверяет
REST API: выдачу слотов, создание, подтверждение и отмену заказа. Оба печатают
сообщение об успешном завершении.
